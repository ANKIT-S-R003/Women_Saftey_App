# 🛡️ SafeGuard – Women Safety Application

SafeGuard is a mobile application designed to provide **quick emergency support**, **trusted contact alerts**, and **access to nearby safety services**.  
It acts as a **personal safety companion** with features like SOS alerts, emergency contacts, and nearby hospitals/police stations.

---

## 🚀 Features

- **Secure Login & Signup**  
  Simple and safe authentication for users.  

- **Emergency SOS Button**  
  Hold for 5 seconds to send alerts with live location to trusted contacts.  

- **Trusted Contacts Management**  
  Add or remove emergency contacts who will be notified instantly.  

- **Nearby Services**  
  Quickly find nearby hospitals and police stations.  

- **Learning Resources**  
  Access protection techniques and safety guidelines.
